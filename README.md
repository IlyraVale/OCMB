# OCMB

A lightweight original-character showcase template built with vanilla HTML, CSS, and JavaScript.

## Features

- profile-style header and visual introduction area
- card-based character presentation
- image-driven character gallery
- animated particle background
- responsive static-page structure
- no framework or build step required

## Project structure

- `index.html` — page structure and showcase layout
- `style.css` — styling, layout, and visual effects
- `script.js` — interactive character-card behavior
- `1.jpg`–`4.jpg` — example character assets
- `tx.jpg`, `bj1.jpg` — profile/background assets

## Usage

Open `index.html` directly in a browser or deploy the repository as a static site.

The content and images can be replaced to reuse the layout as a general character archive or portfolio template.
